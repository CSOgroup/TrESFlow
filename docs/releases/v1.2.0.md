# TrESFlow v1.2.0 — 2026-10-02

Changes since v1.1.1:

- Dependency-aware early FASTQ cleanup waits for every enabled consumer, including QC and optional split-FASTQ compression. Source inputs and published outputs are protected. Set `--cleanup_work false` to retain intermediates and work directories for debugging/resume.
- RNA and DNA now retain complete `CB = XI = <sample>_<group>_<sb_index>_<L1L2L3>` identities across split FASTQs, BAMs, matrices and per-cell outputs. STARsolo counts by full `XI` with molecular UMIs separate; DNA duplicate marking distinguishes cells sharing ligations. DNA marks and AVITI duplicate behavior are preserved.
- A versioned physical oligo lookup supplies exact RNA/single-DNA and dual-DNA sequences. Indices 13–16 add `GATC`, `TGAC`, `CATG`, `TACG` for RNA/single DNA; their dual-DNA entries are explicitly unavailable and cannot be selected.
- Shared or independent modality selections remain available. Optional `sb_oligo_pairings` assigns mismatched physical oligos to a shared logical `sb_index` without changing physical `SB`. List order never implies pairing. Valid independent mismatches warn and continue; conflicting/ambiguous selections fail. Identity warnings appear before preflight and on resume, with readable warnings and a physical-to-logical audit in `pipeline_info`. Lookup or logical identity changes invalidate affected cached tasks.

## Compatibility and regeneration

Existing valid samplesheet inputs, including legacy sequence selectors and modality-specific groups, remain supported. **Output barcode identifiers have changed.** Without explicit pairing, `sb_index` defaults to the physical oligo index.

Previously split, aggregated or deduplicated outputs require regeneration from before splitting/counting/deduplication. Relabeling matrices, cell calls, statistics or duplicate-marked/NoDup BAMs cannot restore merged cells or reverse duplicate decisions. Regenerate from raw FASTQs in fresh output/work directories. Complete suitable upstream intermediates remain biologically reusable, but the normal pipeline has no intermediate import interface; old published split FASTQs and QC sidecars are insufficient.

## Validation evidence

Recorded validation from the merged implementation PRs; no pipeline rerun was performed for this metadata/documentation release preparation:

- [Full cell identities (#6)](https://github.com/CSOgroup/TrESFlow/pull/6): 35 affected-suite tests, 7 focused regressions and 23 nf-test workflow checks passed, including real Codon/Python, STAR, GATK and bwa-mem2 fixtures. A bounded Tonsil1 run used 1,000 RNA and 2,000 single-DNA read pairs; all 64 tasks completed and tags, matrices, statistics, retention and duplicate outputs were audited.
- [Barcode pairings (#7)](https://github.com/CSOgroup/TrESFlow/pull/7): 17 interface/resume tests, 9 focused review tests and 7 FASTQ-compression tests passed. Logical-only `sb_index` changes from 42 to 43 invalidated affected tasks with unchanged physical mapping; resumed warnings and audits were verified. Existing real-tool identity/counting/duplicate evidence was reused.

These bounded checks establish the observed paths; production-scale cell yields, sensitivity and performance remain unvalidated. Production counting and cell-calling thresholds are unchanged.

## Known resume limitation

Pre-existing chromosome preflight rewrites unchanged canonical files with new modification times, causing downstream filtering, coverage and reporting to rerun. Baseline reproduction and earlier/current unchanged-resume traces showed the same 25 cached tasks and 14 reruns; core identity tasks cache correctly with unchanged mapping. This limitation remains outside v1.2.0's changes, as documented in [#7](https://github.com/CSOgroup/TrESFlow/pull/7).
